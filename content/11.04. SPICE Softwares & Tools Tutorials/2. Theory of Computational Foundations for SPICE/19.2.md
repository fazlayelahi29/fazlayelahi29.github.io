# CHAPTER 19: AUTONOMOUS CIRCUIT SIMULATION, SURROGATE MODELING, AND IN-LOOP NEURAL ACCELERATION

## INTRODUCTION 

For over five decades following its inception at the Electronics Research Laboratory of the University of California, Berkeley, in 1973, the Simulation Program with Integrated Circuit Emphasis (SPICE) operated primarily as an interactive, human-in-the-loop verification calculator . In that classical paradigm, an analog or mixed-signal integrated circuit (IC) designer manually drafted schematics within a graphical user interface (GUI), visually configured voltage and current probes, launched a single deterministic netlist simulation, and inspected the resulting waveforms on a virtual oscilloscope. By 2026, the physical and statistical realities of sub-3-nanometer (3nm) gate-all-around (GAA) nanosheet field-effect transistors (NSFETs), complementary FETs (CFETs), and heterogeneous 3D-IC architectures have rendered manual schematic-driven verification mathematically obsolete . The quadratic scaling of multi-gate compact models such as BSIM-CMG, compounded by extreme layout-dependent effects (LDE), self-heating (SH), non-quasi-static (NQS) channel dynamics, and high-sigma local variability, has expanded the verification state space far beyond human cognitive capacity .

Modern Electronic Design Automation (EDA) architectures have consequently decoupled the underlying numerical differential-algebraic equation (DAE) solver from graphical human interfaces . In contemporary semiconductor engineering workflows, SPICE no longer functions as an interactive desktop application; rather, it operates as an autonomous, headless physics microservice orchestrated entirely through programmatic Python frameworks, continuous integration and continuous deployment (CI/CD) pipelines, and machine learning (ML) optimization loops . The deterministic Modified Nodal Analysis (MNA) engine has been transformed into a foundational ground-truth data generator for training physics-informed neural networks (PINNs), deep time-series surrogates, Bayesian Gaussian Process (GP) optimizers, and reinforcement learning (RL) topology synthesis agents . Simultaneously, the internal C and C++ matrix evaluation loops of modern simulators have been re-architected via the Open Simulator Device Interface (OSDI) and the OpenVAF Verilog-A compiler to execute pre-trained neural compact models directly during Newton-Raphson iterations . This nineteenth volume of the definitive treatise on SPICE examines the complete mathematical, software, and architectural evolution of circuit simulation into an AI-native computational discipline.

## 19.1 THE DEATH OF THE GUI: HEADLESS CI/CD SIMULATION

The retirement of the interactive waveform viewer as the primary design interface stems directly from the shift toward software-defined silicon verification. When designing complex mixed-signal blocks—such as high-speed serializer/deserializer (SerDes) transceivers, monolithic gallium nitride (GaN) phase-locked loops (PLLs), or backside integrated voltage regulators (BS-IVRs)—evaluating a single nominal schematic capture provides zero statistical assurance of silicon yield . Modern design teams treat analog netlists, transistor sizing parameters, and Process Design Kit (PDK) model cards as version-controlled source code governed by Git repositories, automated Jenkins orchestration servers, and immutable Docker container clusters .

### CONTAINERIZED ENVIRONMENT IMMUTABILITY AND VERSION CONTROL

In legacy EDA workflows, simulation reproducibility was persistently undermined by environment drift, wherein disparate workstation configurations, dynamic link library mismatches, or unversioned PDK patches produced divergent numerical trajectories across engineering sites. Contemporary IC engineering resolves this vulnerability by encapsulating the entire simulation stack—including headless binaries such as `ngspice` (version 44 and beyond), commercial fast-SPICE solvers, OpenVAF compilers, and open or proprietary PDK libraries—within lightweight, cryptographically hashed Linux containers . Within this paradigm, netlists, behavioral Verilog-A modules, and Python testbenches reside in Git repositories alongside digital register-transfer level (RTL) code . 

Every commit modifying a subcircuit topology, parasitic extraction rule, or compact model parameter triggers a webhook that dispatches a multi-stage Jenkins or GitLab CI pipeline. Because the container images strip away all X11 windowing dependencies, OpenGL rendering libraries, and graphical schematic editors, container initialization overhead drops to milliseconds, allowing Kubernetes clusters to dynamically spin up ten thousand concurrent headless SPICE worker pods across cloud and on-premise high-performance computing (HPC) nodes.

### AUTOMATED REGRESSION GATES AND CONTINUOUS SILICON INTEGRATION

Within a Jenkins-orchestrated regression pipeline, headless SPICE execution is structured as a directed acyclic graph (DAG) of verification stages. Upon a pull request, the pipeline first executes static netlist linting and electrical rule checks (ERC), verifying topological sanity such as the absence of floating gate nodes or shorted voltage sources. The second stage dispatches parallelized DC operating point (`.op`) and small-signal transfer function (`.ac`) sweeps across nominal process-voltage-temperature (PVT) corners, while the third stage launches computationally intensive transient (`.tran`), harmonic balance, and periodic steady-state (PSS) analyses .

| Verification Architecture Dimension | Legacy GUI-Centric Paradigm | 2026 Headless CI/CD & Container Paradigm |
| :--- | :--- | :--- |
| **Execution Invocation** | Manual mouse-driven schematic netlisting and interactive solver launch | Automated Git webhook triggering containerized CLI binaries (`ngspice -b`) |
| **Environment Consistency** | Host-dependent OS libraries, mutable local `.spiceinit` files, manual PDK paths | Immutable Docker/OCI images with pinned OSDI binaries and hashed PDK commits  |

| **Continuous Learning Integration** | Disconnected from historical runs; discarded simulation databases | Continuous data ingestion into empirical Bayes and ML training lakes  |

Rather than writing gigabytes of uncompressed ASCII `.raw` files to network-attached storage—a practice that induces severe input/output (I/O) throttling—headless CI pipelines evaluate pass/fail assertions programmatically in volatile memory. If a commit to a dynamic amplifier subcircuit degrades phase margin below 60 degrees, increases Worst Negative Slack (WNS) in mixed-signal timing paths, or elevates dynamic $V_{DD}$ IR-drop beyond specified tolerances, the Jenkins pipeline automatically rejects the merge request and posts a structured diagnostic report detailing the exact corner and sensitivity vector responsible for the violation . Furthermore, these continuous regression pipelines form the backbone of continuous learning EDA systems; with each successive iteration of a circuit design, telemetry from every regression run is archived into a centralized feature store, enabling empirical Bayes frameworks to adaptively refine physical placement, routing, and sizing heuristics across subsequent tape-out cycles .

## 19.2 SCRIPTING THE SPICE BINARY WITH PYTHON WRAPPERS

To integrate deterministic circuit physics into machine learning frameworks and automated CI/CD pipelines, the communication barrier between high-level algorithmic languages (specifically Python) and low-level compiled SPICE solvers (written in C, C++, or Rust) must be eliminated. Historically, Python automation relied on rudimentary subprocess scripting: a Python script formatted a text string, wrote a `.cir` file to a solid-state drive, invoked the SPICE executable via `subprocess.Popen`, waited for process termination, and parsed the resulting disk file. In 2026, the latency of disk serialization and operating system process creation is unacceptable for iterative optimization loops requiring millions of evaluations. Modern architectures utilize object-oriented abstract syntax trees (ASTs) via frameworks like `PySpice` alongside direct, in-memory C-shared library bindings (`libngspice.so`) via Python's `ctypes` and `cffi` interfaces .

### IN-MEMORY SHARED LIBRARY ARCHITECTURE AND CALLBACK PIPELINES

When SPICE is compiled as a position-independent shared object (`libngspice`), the entire solver engine—including the lexical netlist parser, the sparse matrix package (`Sparse 1.3` or `KLU`), the device evaluation routines, and the numerical integration state machine—resides directly within the virtual address space of the host Python interpreter. Communication between the Python orchestrator and the C binary occurs through asynchronous C-pointer callbacks registered during initialization: `SendChar` (capturing standard output and error streams), `SendData` (streaming instantaneous node voltages and branch currents at every accepted internal timestep), and `ControlledExit` (handling convergence failures without crashing the host interpreter).

Through this shared-memory architecture, a Python wrapper loads a base netlist topology once into the C heap. Subsequent parameter sweeps or Monte Carlo mutations bypass the lexical parser entirely; the Python wrapper issues `alter` and `altermod` commands directly to the internal C data structures, modifies device instance pointers in microseconds, and triggers a fresh `bg_run` (background thread execution) or synchronous `run` call. As the solver advances through time $t_k$, the `SendData` callback intercepts the double-precision `pvecvaluesall` C-struct array and maps the memory buffer directly into a zero-copy NumPy array or a PyTorch tensor on the CPU, ready for immediate GPU transfer .

### PRODUCTION IMPLEMENTATION: ZERO-DISK IN-MEMORY LIBNGSPICE HARNESS

The following production-ready Python module demonstrates an industrial-grade, headless `libngspice` wrapper that dynamically manipulates transistor dimensions in memory, executes a transient simulation, and streams the resulting waveform vectors directly into PyTorch tensors without touching the filesystem.

```python
import ctypes
from ctypes import c_char_p, c_int, c_double, c_bool, c_void_p, POINTER, Structure, CFUNCTYPE
import numpy as np
import torch
from typing import Dict, List, Optional

# Define C-structures matching the official ngspice shared library API (sharedspice.h)
class NgComplex(Structure):
    _fields_ = [("cx_real", c_double), ("cx_imag", c_double)]

class VecValues(Structure):
    _fields_ = [
        ("name", c_char_p),
        ("creal", c_double),
        ("cimag", c_double),
        ("is_scale", c_bool),
        ("is_complex", c_bool)
    ]

class VecValuesAll(Structure):
    _fields_ = [
        ("veccount", c_int),
        ("vecindex", c_int),
        ("vecsa", POINTER(POINTER(VecValues)))
    ]

# Callback function prototypes
SEND_CHAR_FUNC = CFUNCTYPE(c_int, c_char_p, c_int, c_void_p)
SEND_STAT_FUNC = CFUNCTYPE(c_int, c_char_p, c_int, c_void_p)
CONTROLLED_EXIT_FUNC = CFUNCTYPE(c_int, c_int, c_bool, c_bool, c_int, c_void_p)
SEND_DATA_FUNC = CFUNCTYPE(c_int, POINTER(VecValuesAll), c_int, c_int, c_void_p)
SEND_INIT_DATA_FUNC = CFUNCTYPE(c_int, c_void_p, c_int, c_void_p)
BG_THREAD_RUNNING_FUNC = CFUNCTYPE(c_int, c_bool, c_int, c_void_p)

class HeadlessSpiceEngine:
    """
    In-memory C-shared library interface to libngspice for zero-disk-IO 
    netlist mutation and direct PyTorch tensor extraction.
    """
    def __init__(self, lib_path: str = "libngspice.so", device: str = "cpu"):
        self.device = torch.device(device)
        self.lib = ctypes.CDLL(lib_path)
        self._storage: Dict[str, List[float]] = {}
        self.exit_status: int = 0
        
        # Keep C-callback references alive in Python memory to prevent garbage collection
        self._cb_char = SEND_CHAR_FUNC(self._send_char_cb)
        self._cb_stat = SEND_STAT_FUNC(self._send_stat_cb)
        self._cb_exit = CONTROLLED_EXIT_FUNC(self._exit_cb)
        self._cb_data = SEND_DATA_FUNC(self._send_data_cb)
        self._cb_init = SEND_INIT_DATA_FUNC(self._send_init_cb)
        self._cb_bg = BG_THREAD_RUNNING_FUNC(self._bg_running_cb)
        
        self.lib.ngSpice_Init.argtypes = [
            SEND_CHAR_FUNC, SEND_STAT_FUNC, CONTROLLED_EXIT_FUNC,
            SEND_DATA_FUNC, SEND_INIT_DATA_FUNC, BG_THREAD_RUNNING_FUNC, c_void_p
        ]
        self.lib.ngSpice_Init.restype = c_int
        self.lib.ngSpice_Command.argtypes = [c_char_p]
        self.lib.ngSpice_Command.restype = c_int
        self.lib.ngSpice_Circ.argtypes = [POINTER(c_char_p)]
        self.lib.ngSpice_Circ.restype = c_int

        self.lib.ngSpice_Init(
            self._cb_char, self._cb_stat, self._cb_exit,
            self._cb_data, self._cb_init, self._cb_bg, None
        )

    def _send_char_cb(self, msg: bytes, ident: int, user_data: c_void_p) -> int:
        return 0

    def _send_stat_cb(self, msg: bytes, ident: int, user_data: c_void_p) -> int:
        return 0

    def _exit_cb(self, status: int, immediate: bool, quit_exit: bool, ident: int, user_data: c_void_p) -> int:
        self.exit_status = status
        return status

    def _send_init_cb(self, vec_info: c_void_p, ident: int, user_data: c_void_p) -> int:
        self._storage.clear()
        return 0

    def _bg_running_cb(self, is_running: bool, ident: int, user_data: c_void_p) -> int:
        return 0

    def _send_data_cb(self, pvec: POINTER(VecValuesAll), count: int, ident: int, user_data: c_void_p) -> int:
        v_all = pvec.contents
        for i in range(v_all.veccount):
            vec = v_all.vecsa[i].contents
            vec_name = vec.name.decode("utf-8").lower()
            if vec_name not in self._storage:
                self._storage[vec_name] = []
            self._storage[vec_name].append(vec.creal)
        return 0

    def load_netlist(self, netlist_lines: List[str]) -> None:
        c_array = (c_char_p * (len(netlist_lines) + 2))()
        for idx, line in enumerate(netlist_lines):
            c_array[idx] = line.encode("utf-8")
        c_array[len(netlist_lines)] = b".end"
        c_array[len(netlist_lines) + 1] = None
        self.lib.ngSpice_Circ(c_array)

    def mutate_parameter(self, device_or_param: str, param_name: str, value: float) -> None:
        cmd = f"alter {device_or_param} {param_name} = {value:.6e}".encode("utf-8")
        self.lib.ngSpice_Command(cmd)

    def run_transient(self, t_step: str = "1p", t_stop: str = "1n") -> Dict[str, torch.Tensor]:
        self._storage.clear()
        cmd = f"tran {t_step} {t_stop}".encode("utf-8")
        self.lib.ngSpice_Command(cmd)
        
        tensors: Dict[str, torch.Tensor] = {}
        for key, val_list in self._storage.items():
            np_arr = np.asarray(val_list, dtype=np.float32)
            tensors[key] = torch.from_numpy(np_arr).to(self.device)
        
        # Free internal C memory plots to prevent memory leaks across 100k+ runs
        self.lib.ngSpice_Command(b"destroy all")
        return tensors
```

By invoking `destroy all` inside the C heap immediately after tensor conversion, this architecture maintains a flat memory footprint even when executing millions of sequential simulations inside a long-running training daemon.

## 19.3 GENERATING MASSIVE SYNTHETIC ML DATASETS VIA SPICE

Deep neural networks are notoriously data-hungry, requiring tens of thousands to millions of labeled trajectories to generalize across high-dimensional nonlinear manifolds without overfitting . In experimental semiconductor physics, acquiring such data volumes via physical silicon wafer probing or Technology Computer-Aided Design (TCAD) finite-element simulation is economically and computationally intractable . Consequently, modern EDA pipelines utilize calibrated SPICE engines as high-throughput ground-truth physics generators, synthesizing massive datasets that bridge the gap between physical TCAD equations and fast, design-oriented machine learning models .

### HIGH-DIMENSIONAL DESIGN AND PROCESS SPACE SAMPLING

To construct a comprehensive synthetic training corpus—such as the standardized Emerging Semiconductor Device Benchmark (ESDED) or datasets for Gate-All-Around (GAA) nanosheet technologies—random uniform sampling is insufficient . Because transistor dynamics exhibit extreme exponential sensitivity in subthreshold regimes and abrupt curvature transitions near velocity saturation or ferroelectric polarization switching, uniform grid sampling wastes computational cycles in linear regions while undersampling critical nonlinear thresholds .

Modern synthetic data generators employ quasi-random, low-discrepancy sequences—specifically Sobol sequences and Latin Hypercube Sampling (LHS)—combined with physics-aware importance sampling and voltage symmetry reductions . For instance, when generating training data from a calibrated BSIM-CMG model for a GAA technology node, the sampling space spans geometric, oxide, and thermal dimensions simultaneously: channel length $L \in [12\text{ nm}, 50\text{ nm}]$, nanosheet width $W \in [20\text{ nm}, 40\text{ nm}]$, equivalent oxide thickness $\text{EOT} \in [8\text{ \AA}, 10\text{ \AA}]$, and ambient temperature $T \in [-50^\circ\text{C}, 125^\circ\text{C}]$ (or extended military/cryogenic ranges from $-125^\circ\text{C}$ to $125^\circ\text{C}$) . By applying intrinsic drain-source voltage symmetry constraints, the dimensionality of the bias sweep ($V_{GS}, V_{DS}, V_{BS}$) is halved, immediately doubling effective dataset density .

### DATA PREPROCESSING, LOGARITHMIC SCALING, AND DERIVATIVE EXTRACTION

A major pitfall in training neural networks on raw SPICE data is the multi-decade dynamic range of physical quantities . Drain current $I_{DS}$ spans over twelve orders of magnitude, from femtoamperes ($10^{-15}\text{ A}$) in the off-state leakage regime to milliamperes ($10^{-3}\text{ A}$) in strong inversion. Training a neural network with standard Mean Squared Error (MSE) on raw linear currents results in a model that completely ignores subthreshold slope and leakage, rendering it useless for static random-access memory (SRAM) retention or low-power IoT circuit analysis .

To guarantee accuracy across all operating regimes, synthetic SPICE pipelines extract both the primary physical quantities (terminal currents $I_D, I_G, I_S, I_B$ and intrinsic/parasitic terminal charges $Q_G, Q_D, Q_S, Q_B$) and their exact analytical Jacobians (transconductance $g_m = \partial I_D / \partial V_{GS}$, output conductance $g_{ds} = \partial I_D / \partial V_{DS}$, and transcapacitances $C_{ij} = \partial Q_i / \partial V_j$) directly from the SPICE operating point structures . The pipeline then applies dual-scale preprocessing transformations, mapping linear and logarithmic spaces into a unified normalized tensor representation :

$\tilde{I}_{DS}(V) = \frac{\ln\left(\max(|I_{DS}(V)|, I_{\text{floor}}) / I_0\right)}{\sigma_{\ln I}} \oplus \frac{I_{DS}(V)}{\sigma_{I}}$

Furthermore, to ensure thermodynamic conservation—specifically that terminal currents equal exactly zero when all terminal bias voltages equal zero ($I_D = I_G = 0$ at $\mathbf{V} = \mathbf{0}$)—the synthetic pipeline structures the target outputs as quasi-physical proportionality factors rather than raw unconstrained currents, eliminating non-physical zero-bias offsets prior to disk serialization in compressed HDF5 or Apache Parquet formats .

## 19.4 THE COMPUTATIONAL BOTTLENECK OF MONTE CARLO IN 2026

While synthetic dataset generation is a one-time offline expenditure, statistical yield verification during active circuit design represents an acute runtime crisis . At the 3nm and sub-3nm technology nodes, physical dimensions approach atomic scales, causing discrete random dopant fluctuations (RDF), line-edge roughness (LER), metal gate granularity (MGG), and oxide thickness variations to dominate electrical behavior . Furthermore, in emerging memory and logic architectures—such as 2D material channel FETs ($\text{MoS}_2$), Dual-Gate Tunnel FETs (DG-TFETs), and resistive random-access memory (RRAM) crossbars plagued by nanoscale bottom-electrode (BE) roughness—device-to-device and cycle-to-cycle variability grows severely non-Gaussian .

### THE CURSE OF DIMENSIONALITY AND QUADRATIC COMPACT MODEL SCALING

In modern system-on-chip (SoC) architectures, critical blocks such as high-density SRAM arrays (comprising tens of millions of bitcells) or high-speed clock distribution networks must achieve failure rates below $10^{-9}$, corresponding to six-sigma ($6\sigma$) or seven-sigma ($7\sigma$) statistical verification . In a brute-force Monte Carlo (MC) simulation, estimating a failure probability $P_f$ with a relative error $\epsilon$ at a confidence level $1-\alpha$ requires $N_{\text{MC}}$ independent SPICE simulations, governed by the variance of the Bernoulli estimator :

$N_{\text{MC}} \approx \frac{z_{1-\alpha/2}^2 (1 - P_f)}{\epsilon^2 P_f}$

For a $6\sigma$ rare event where $P_f \approx 1.0 \times 10^{-9}$ and a desired relative error of $\epsilon = 0.1$, brute-force Monte Carlo demands $N_{\text{MC}} \approx 3.8 \times 10^{11}$ full transient SPICE simulations . Simultaneously, each individual SPICE simulation has become drastically slower. Advanced multi-gate compact models like BSIM-CMG require solving complex implicit surface-potential equations and quantum mechanical confinement corrections at every Newton-Raphson iteration, exhibiting quadratic runtime scaling with respect to circuit complexity . When combined with thousand-corner Process-Voltage-Temperature (PVT) matrices and extracted post-layout RC parasitic networks containing millions of coupling capacitors, standard SPICE engines hit an insurmountable computational wall .

### VARIANCE REDUCTION AND GENERATIVE STATISTICAL LIBRARIES

To break this computational deadlock, 2026 verification flows replace standard Monte Carlo sampling with Adaptive AI and Additive AI high-sigma methodologies . Rather than simulating millions of nominal points near the mean of the Gaussian process distribution, variability-aware control-variate-assisted neural networks and Gaussian Process classifiers actively learn the failure boundary in the high-dimensional parameter space . Once the surrogate identifies the region of maximum failure likelihood, importance sampling shifts the sampling probability density function $p(\mathbf{x})$ toward the tail distribution $q(\mathbf{x})$, concentrating actual SPICE evaluations strictly along the failure manifold .

At the standard-cell library characterization level, calibrating Liberty Variation Format (LVF) models to capture local device mismatch across PVT corners previously consumed weeks of datacenter compute time . Modern generative AI engines such as `LVFGen` bypass exhaustive Monte Carlo sweeps by learning the latent statistical correlations across cell topologies and slews/loads, achieving a $2.27\times$ speedup at a 5,000-sample Monte Carlo accuracy threshold and a $4.06\times$ speedup over state-of-the-art Quasi-Monte Carlo (QMC) methods at a 100,000-sample accuracy level . Similarly, when characterizing Static Timing Analysis (STA) current source models (CSMs), machine learning acceleration techniques deliver $4\times$ runtime speedups with a negligible $0.4\%$ accuracy loss .

## 19.5 WHAT IS AN AI SURROGATE MODEL IN EDA?

The fundamental paradigm shift in 2026 circuit simulation is the formal decoupling of physical behavior prediction from iterative numerical matrix inversion . In traditional SPICE, determining the DC, AC, or transient response of a circuit requires formulating the Modified Nodal Analysis (MNA) system of nonlinear Differential Algebraic Equations (DAEs) :

$\mathbf{F}(\mathbf{x}(t), \dot{\mathbf{x}}(t), t) = \mathbf{I}(\mathbf{x}(t)) + \frac{d\mathbf{Q}(\mathbf{x}(t))}{dt} + \mathbf{G}\mathbf{x}(t) - \mathbf{u}(t) = \mathbf{0}$

where $\mathbf{x}(t) \in \mathbb{R}^N$ represents the vector of unknown node voltages and branch currents, $\mathbf{I}(\mathbf{x})$ and $\mathbf{Q}(\mathbf{x})$ represent nonlinear device currents and charges, $\mathbf{G}$ denotes the linear conductance matrix, and $\mathbf{u}(t)$ is the independent source excitation vector . Solving this system requires discretizing the time derivative $\frac{d\mathbf{Q}}{dt}$ via Backward Euler, Trapezoidal, or Gear integration methods, and iteratively linearizing the resulting algebraic system at every discrete timestep $t_n$ via the Newton-Raphson algorithm :

$\mathbf{J}(\mathbf{x}_n^{(k)}) \left( \mathbf{x}_n^{(k+1)} - \mathbf{x}_n^{(k)} \right) = -\mathbf{F}(\mathbf{x}_n^{(k)}, \dot{\mathbf{x}}_n^{(k)}, t_n), \quad \text{where } \mathbf{J}(\mathbf{x}) = \frac{\partial \mathbf{I}}{\partial \mathbf{x}} + \alpha_0 \frac{\partial \mathbf{Q}}{\partial \mathbf{x}} + \mathbf{G}$

Each Newton-Raphson iteration $k$ demands evaluating complex compact model equations for every device to stamp entries into the sparse Jacobian matrix $\mathbf{J}$, followed by an $O(N^\gamma)$ sparse LU factorization ($\gamma \approx 1.2 \text{ to } 1.8$). If strong nonlinearities—such as abrupt polarization switching in a ferroelectric capacitor or sharp threshold transitions in a tunnel FET—cause the Newton-Raphson update to overshoot, the solver fails to converge, rejects the timestep, halves $\Delta t$, and repeats the entire matrix factorization sequence .

### REPLACING THE MNA SOLVER WITH DIFFERENTIABLE FORWARD INFERENCE

An AI surrogate model in EDA completely eliminates the Newton-Raphson loop, the sparse LU factorization, and the numerical timestepping bottleneck during inference . Formally, a surrogate model is a parameterized, infinitely differentiable mathematical operator $\mathcal{M}_{\theta}: \mathcal{P} \times \mathcal{U} \rightarrow \mathcal{Y}$, implemented as a deep neural network with learned weights $\theta$, that maps circuit design, geometry, and process parameters $\mathbf{p} \in \mathcal{P}$ along with excitation waveforms $\mathbf{u}(t) \in \mathcal{U}$ directly to the solution trajectory $\hat{\mathbf{x}}(t) \in \mathcal{Y}$ .

Instead of solving an implicit system of equations sequentially step-by-step, evaluating the surrogate model reduces to a sequence of dense matrix-matrix multiplications and element-wise nonlinear activation functions executed in parallel on GPUs or neural processing units (NPUs) . As demonstrated in benchmark PINN simulators such as `NeuroSPICE`, once trained, predicting the complete transient response of nonlinear MOSFET amplifiers, self-oscillating five-stage ring oscillators, or coupled Landau-Khalatnikov ferroelectric RAM (FeRAM) cells requires a constant inference time of approximately $200\text{ }\mu\text{s}$—yielding speedups of $100\times$ to $10,000\times$ compared to conventional SPICE solvers or TCAD engines .


### EXTRAPOLATION FAILURE OF BLACK-BOX MODELS VERSUS PHYSICS-CONSTRAINED ARCHITECTURES

A critical insight established across recent semiconductor modeling research is that pure black-box Artificial Neural Networks (ANNs) fail catastrophically when queried outside their training hull . As demonstrated by the empirical benchmarks, when a pure black-box ANN and a physics-informed neural network are trained on BSIM-CMG data across five discrete temperatures ($T = -85^\circ\text{C}, -45^\circ\text{C}, 5^\circ\text{C}, 45^\circ\text{C}, \text{ and } 85^\circ\text{C}$), both achieve exceptional accuracy within the training bounds, recording Root Mean Square Error (RMSE) values of $0.5\%$ and $0.4\%$, respectively . However, when the circuit simulator queries the models at extreme cryogenic or automotive junction temperatures outside the training range ($T = -125^\circ\text{C}$ and $125^\circ\text{C}$), the RMSE of the pure black-box ANN spikes by more than an order of magnitude to $7.6\%$, accompanied by non-physical negative conductances that crash the circuit simulator . Conversely, the physics-constrained neural network maintains a remarkably low RMSE of $0.7\%$ across the unseen temperature extremes .

To achieve this physical consistency, modern EDA surrogates embed fundamental semiconductor physics directly into the network topology . In the Charge-Based Prior Knowledge Input with Difference (PKID-ANN) architecture and quasi-physical GAA models, low-fidelity analytical expressions (such as the Grove-Frohman equation or Taylor-expanded surface-potential mobility relations) provide a baseline physical scaffold, while the neural network learns only the high-order quantum and short-channel residual corrections . For short-channel GAA nanosheet devices where drain current ceases to scale inversely with channel length ($1/L$), the surrogate incorporates a quasi-physical correction function :

$I_{DS,\text{surrogate}}(V, L, W, T) = \frac{W}{L(1 + \alpha L)} \cdot \mu_r(E_\perp, \phi_{DS}, T) \cdot \mathcal{N}_{\theta}^{(I)}(V_{GS}, V_{DS}, T)$

where $\alpha$ is a pre-extracted short-channel fitting parameter, $\phi_{DS} = (q_{is} - q_{id})/C_{ox}$ estimates the surface potential difference between source and drain from normalized intrinsic charges, $E_\perp = q_{ig}/\epsilon_s$ estimates the vertical electric field, and $\mu_r$ encapsulates phonon scattering ($DUA$), Coulombic scattering ($DUD$), and velocity saturation ($DSAT$, placed in the numerator for enhanced fitting flexibility) :

$\mu_r = \frac{\mu_{r0} + \text{DSAT} \cdot \phi_{DS}}{1 + \text{DUA} \cdot E_\perp + \text{DUD} \cdot q_{is}^{-1/3}}$

Because these quasi-physical parameters retain exact physical meaning, circuit designers can adapt a pre-trained neural compact model to an entirely different foundry process—such as fitting experimental IBM GAA silicon data using a network originally trained on synthetic BSIM-CMG data—simply by adjusting three scalar parameters ($m$, $\mu_{r0}$, and $\text{DSAT}$) post-training without retraining the neural network weights . In full circuit simulations including SRAM static noise margin (SNM) and ring oscillator transient verification, this quasi-physical neural surrogate accounts for all terminal currents, charges, self-heating, and non-quasi-static effects while reducing total SPICE simulation time by over $80\%$ .

## 19.6 TRAINING NEURAL NETWORKS TO PREDICT MNA OUTCOMES

When transitioning from single-device compact modeling to subcircuit-level or full-block MNA waveform prediction, the machine learning architecture must explicitly capture chronological stateful recurrence and continuous-time differential dynamics . Unlike static DC transfer curves, transient circuit behavior depends on the historical integration of charge in capacitors, flux in inductors, and latent thermal energy in 3D neuromorphic or power stacks .

### VECTORIZING VARIABLE-TIMESTEP SPICE TRAJECTORIES INTO TENSORS

A fundamental data engineering challenge in training sequence models—such as Long Short-Term Memory (LSTM) networks, structure-regularized recurrent units like $\Psi$-Vortex, or causal Transformers—on SPICE outputs is that SPICE utilizes an adaptive, non-uniform internal timestep $\Delta t_n = t_n - t_{n-1}$ governed by Local Truncation Error (LTE) estimates . During quiescent intervals, $\Delta t_n$ expands to nanoseconds, whereas during a sharp clock edge or ring oscillator transition, $\Delta t_n$ contracts to femtoseconds. 

Formatting these irregular vectors into uniform three-dimensional PyTorch batches of shape `(Batch_Size, Sequence_Length, Feature_Dim)` requires specialized temporal alignment pipelines in 2026 . The first approach employs Piecewise Cubic Hermite Interpolating Polynomial (PCHIP) resampling; unlike standard cubic splines that introduce non-physical Gibbs ringing and voltage overshoot around sharp square-wave edges, PCHIP preserves monotonicity, resampling variable-step SPICE trajectories onto a fixed clock grid $t \in [0, T_{\text{max}}]$ without violating supply rail bounds. The second approach utilizes time-delta conditioned tokenization for causal Transformer and stateful recurrent architectures, wherein the raw irregular integration steps are retained and the instantaneous step size $\Delta t_n$ is concatenated directly onto the input feature vector $\mathbf{z}_n = [\mathbf{u}(t_n), \Delta t_n, \mathbf{p}]^T$, enabling the attention mechanism or recurrent gate to dynamically scale its state integration across variable time horizons and storage delays .

### PHYSICS-INFORMED LOSS FUNCTIONS AND DIFFERENTIAL ALGEBRAIC CONSTRAINTS

When training a neural network to predict MNA outcomes, relying strictly on data-driven L2 waveform loss often yields models that violate Kirchhoff's Current Law (KCL) or fail to conserve charge during transient transitions . To enforce physical validity, frameworks such as `NeuroSPICE` formulate the training objective as a Physics-Informed Neural Network (PINN) whose loss function explicitly penalizes violations of the underlying circuit Differential Algebraic Equations (DAEs) and initial conditions (I.C.) .

Let $\hat{\mathbf{x}}_{\theta}(t)$ denote the vector of node voltages (such as drain voltage $V_D$ and gate voltage $V_G$) predicted by a 4-layer fully connected neural network with 50 neurons per hidden layer and smooth hyperbolic tangent ($\tanh$) activation functions . Using PyTorch's exact automatic differentiation engine (`torch.autograd.grad`), the time derivative $\frac{d\hat{\mathbf{x}}_{\theta}(t)}{dt}$ is computed analytically through the computational graph . For circuits incorporating emerging strongly nonlinear devices—such as a ferroelectric RAM (FeRAM) cell governed by the Landau-Khalatnikov (LK) dynamic polarization equation coupled to a MOSFET—the LK state equation relates electric field $E_{\text{FE}}$ to polarization $P$ via material constants $\alpha_1, \alpha_{11}, \alpha_{111}$ and viscosity coefficient $\rho$ :

$\rho \frac{dP(t)}{dt} + 2\alpha_1 P(t) + 4\alpha_{11} P^3(t) + 6\alpha_{111} P^5(t) = E_{\text{FE}}(t) = \frac{V_{\text{FE}}(t)}{t_{\text{FE}}}$

The total composite loss function $\mathcal{L}_{\text{total}}(\theta)$ minimized by the Adam optimizer combines the supervised data discrepancy against reference SPICE trajectories ($\mathcal{L}_{\text{data}}$), the unsupervised KCL and LK differential algebraic residual across $N_c$ collocation time points ($\mathcal{L}_{\text{DAE}}$), and the initial condition constraint at $t=0$ ($\mathcal{L}_{\text{IC}}$) :

$\mathcal{L}_{\text{total}}(\theta) = \lambda_{\text{data}} \frac{1}{N_d} \sum_{i=1}^{N_d} \left\| \hat{\mathbf{x}}_{\theta}(t_i) - \mathbf{x}_{\text{SPICE}}(t_i) \right\|_2^2 + \lambda_{\text{DAE}} \frac{1}{N_c} \sum_{j=1}^{N_c} \left\| \mathbf{I}\left(\hat{\mathbf{x}}_{\theta}(t_j)\right) + \mathbf{C}\left(\hat{\mathbf{x}}_{\theta}(t_j)\right) \frac{d\hat{\mathbf{x}}_{\theta}(t_j)}{dt} + \mathbf{G}\hat{\mathbf{x}}_{\theta}(t_j) - \mathbf{u}(t_j) \right\|_2^2 + \lambda_{\text{IC}} \left\| \hat{\mathbf{x}}_{\theta}(0) - \mathbf{x}_0 \right\|_2^2$

A critical architectural decision in this formulation is the selection of $\tanh$ (or `Softplus`/`SiLU`) activation functions over Rectified Linear Units (`ReLU`) . Because `ReLU` has a discontinuous first derivative and an identically zero second derivative ($\frac{d^2}{dx^2}\text{ReLU}(x) = 0$), networks built with `ReLU` cannot represent smooth transconductance derivatives ($g_m$) or high-order harmonic distortion terms, whereas $\tanh$ is infinitely continuously differentiable ($C^\infty$), guaranteeing smooth higher-order derivatives during both PINN training and AC harmonic balance analyses .

### PRODUCTION PYTORCH CODE: HYBRID LSTM-TRANSFORMER AND PINN MNA TRAINER

The following production-ready Python code integrates the headless SPICE engine with PyTorch to generate synthetic transient trajectories on the fly and train a physics-informed neural surrogate that jointly minimizes waveform error and KCL differential residuals.

```python
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader
from typing import Tuple

class MNAPhysicsInformedSurrogate(nn.Module):
    """
    A 4-layer Tanh-activated PINN / Recurrent Surrogate designed to predict 
    continuous-time MNA node voltages while supporting exact autograd time derivatives.
    """
    def __init__(self, in_features: int = 4, hidden_dim: int = 50, out_nodes: int = 2):
        super().__init__()
        # 4-layer architecture with 50 neurons per hidden layer and Tanh activation
        self.net = nn.Sequential(
            nn.Linear(in_features, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, out_nodes)
        )
        # Initialize weights using Xavier uniform for optimal Tanh gradient flow
        for m in self.net.modules():
            if isinstance(m, nn.Linear):
                nn.init.xavier_uniform_(m.weight)
                nn.init.zeros_(m.bias)

    def forward(self, t: torch.Tensor, params: torch.Tensor) -> torch.Tensor:
        # Concatenate time vector t (requires_grad=True) with circuit parameters
        x_in = torch.cat([t, params], dim=-1)
        return self.net(x_in)

def compute_dae_pinn_loss(
    model: MNAPhysicsInformedSurrogate,
    t_colloc: torch.Tensor,
    params: torch.Tensor,
    v_target: torch.Tensor,
    v_init: torch.Tensor,
    c_load: float = 1e-14,
    g_load: float = 1e-4
) -> Tuple[torch.Tensor, dict]:
    """
    Computes composite loss: Supervised Waveform MSE + Unsupervised KCL DAE Residual + Initial Condition.
    """
    t_colloc = t_colloc.clone().detach().requires_grad_(True)
    v_pred = model(t_colloc, params)  # Shape: [Batch, Seq_Len, 2] -> [V_G, V_D]
    
    vg_pred = v_pred[..., 0:1]
    vd_pred = v_pred[..., 1:2]
    
    # Compute exact analytical time derivative d(V_D)/dt via PyTorch autograd
    dvd_dt = torch.autograd.grad(
        outputs=vd_pred,
        inputs=t_colloc,
        grad_outputs=torch.ones_like(vd_pred),
        create_graph=True,
        retain_graph=True
    )[0]
    
    # Simplified physical drain current anchor for DAE KCL check at Drain node:
    # C_L * dV_D/dt + G_L * (V_D - V_DD) + I_DS(V_G, V_D) = 0
    v_dd = 1.0
    v_th = 0.25
    k_n = 2.5e-4
    v_ov = torch.nn.functional.softplus(vg_pred - v_th, beta=20.0)
    i_ds = k_n * (v_ov ** 2) * torch.tanh(5.0 * vd_pred)
    
    # Normalize currents to milliampere scale for balanced gradient magnitudes
    kcl_residual = (c_load * dvd_dt + g_load * (vd_pred - v_dd) + i_ds) * 1e3
    
    loss_data = nn.functional.mse_loss(v_pred, v_target)
    loss_dae = torch.mean(kcl_residual ** 2)
    loss_ic = nn.functional.mse_loss(v_pred[:, 0, :], v_init)
    
    total_loss = 1.0 * loss_data + 0.1 * loss_dae + 10.0 * loss_ic
    metrics = {
        "loss_total": total_loss.item(),
        "loss_data": loss_data.item(),
        "loss_dae": loss_dae.item(),
        "loss_ic": loss_ic.item()
    }
    return total_loss, metrics
```

## 19.7 BAYESIAN OPTIMIZATION FOR TRANSISTOR SIZING

Once a circuit topology is selected, determining the optimal physical dimensions—channel widths $W_i$, lengths $L_i$, number of nanosheet fins or fingers $N_{f,i}$, passive resistor and capacitor values, and biasing currents—to simultaneously satisfy competing Power, Performance, and Area (PPA) specifications is a highly non-convex, constrained black-box optimization problem . Because evaluating every candidate sizing vector $\mathbf{x} \in \mathcal{X} \subset \mathbb{R}^d$ across full post-layout corners and Monte Carlo mismatch suites requires expensive SPICE simulations, evolutionary algorithms (such as genetic algorithms or particle swarm optimization) that require tens of thousands of evaluations are computationally prohibitive . Bayesian Optimization (BO) has consequently emerged as the mathematical standard for sample-efficient analog transistor sizing, bi-level metal-density optimization (`BLADE`), and automated SRAM compiler banking (`Split-and-Sync`) .

### GAUSSIAN PROCESS SURROGATE FORMULATION

Bayesian Optimization constructs a probabilistic surrogate model of the expensive SPICE objective function $f(\mathbf{x})$—such as minimizing total static and dynamic power consumption—alongside independent probabilistic models for $M$ nonlinear performance constraints $c_m(\mathbf{x}) \ge 0$ (such as DC open-loop gain $A_0 \ge 70\text{ dB}$, unity-gain bandwidth $\text{UGB} \ge 1\text{ GHz}$, phase margin $\text{PM} \ge 60^\circ$, or SRAM Static Noise Margin) . Each unknown function is modeled as a sample path from a Gaussian Process (GP) prior :

$f(\mathbf{x}) \sim \mathcal{GP}\left(\mu_0(\mathbf{x}), k(\mathbf{x}, \mathbf{x}')\right)$

where $\mu_0(\mathbf{x})$ is the prior mean function and $k(\mathbf{x}, \mathbf{x}')$ is a positive-definite covariance kernel. Because physical circuit responses are continuously differentiable but exhibit sharp localized curvature changes as transistors transition between subthreshold, triode, and saturation regimes, modern EDA frameworks favor the Automatic Relevance Determination (ARD) Matérn-$5/2$ kernel over the overly smooth Radial Basis Function (RBF) kernel:

$k_{\text{Matérn-}5/2}(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \left( 1 + \sqrt{5}\, r(\mathbf{x}, \mathbf{x}') + \frac{5}{3}\, r^2(\mathbf{x}, \mathbf{x}') \right) \exp\left(-\sqrt{5}\, r(\mathbf{x}, \mathbf{x}')\right)$

where the scaled Mahalanobis distance is defined by distinct learned length-scales $\ell_j$ for each transistor parameter $j \in \{1, \dots, d\}$:

$r(\mathbf{x}, \mathbf{x}') = \sqrt{\sum_{j=1}^{d} \frac{(x_j - x'_j)^2}{\ell_j^2}}$

Given a dataset of $t$ completed SPICE evaluations $\mathcal{D}_t = \{(\mathbf{x}_i, y_i)\}_{i=1}^t$ with noisy observations $y_i = f(\mathbf{x}_i) + \epsilon_i$ where $\epsilon_i \sim \mathcal{N}(0, \sigma_n^2)$, conditioning the joint Gaussian distribution yields closed-form analytical expressions for the posterior predictive mean $\mu_t(\mathbf{x})$ and posterior variance $\sigma_t^2(\mathbf{x})$ at any unevaluated sizing candidate $\mathbf{x}$:

$\mu_t(\mathbf{x}) = \mu_0(\mathbf{x}) + \mathbf{k}_t(\mathbf{x})^T \left( \mathbf{K}_t + \sigma_n^2 \mathbf{I} \right)^{-1} (\mathbf{y}_t - \boldsymbol{\mu}_0)$

$\sigma_t^2(\mathbf{x}) = k(\mathbf{x}, \mathbf{x}) - \mathbf{k}_t(\mathbf{x})^T \left( \mathbf{K}_t + \sigma_n^2 \mathbf{I} \right)^{-1} \mathbf{k}_t(\mathbf{x})$

where $[\mathbf{K}_t]_{i,j} = k(\mathbf{x}_i, \mathbf{x}_j)$ is the $t \times t$ Gram matrix and $\mathbf{k}_t(\mathbf{x}) = [k(\mathbf{x}, \mathbf{x}_1), \dots, k(\mathbf{x}, \mathbf{x}_t)]^T$.

### CONSTRAINED ACQUISITION FUNCTIONS AND DIFFUSION PRIORS

To decide which transistor sizing vector $\mathbf{x}_{t+1}$ to simulate next in SPICE, Bayesian Optimization maximizes a lightweight acquisition function $\alpha(\mathbf{x})$ that balances exploitation (sampling where $\mu_t(\mathbf{x})$ predicts optimal performance) and exploration (sampling where uncertainty $\sigma_t(\mathbf{x})$ is high) . Let $f_{\min}^+$ denote the best feasible objective value observed across all previous SPICE runs. The standard Expected Improvement ($\text{EI}$) is weighted by the joint Probability of Feasibility ($\text{PoF}$) across all $M$ independent constraint GPs, forming the Constrained Expected Improvement ($\text{cEI}$) acquisition function:

$\alpha_{\text{cEI}}(\mathbf{x}) = \text{EI}(\mathbf{x}) \prod_{m=1}^{M} \text{Pr}\left(c_m(\mathbf{x}) \ge 0\right) = \sigma_t(\mathbf{x}) \left[ \gamma(\mathbf{x}) \Phi(\gamma(\mathbf{x})) + \phi(\gamma(\mathbf{x})) \right] \prod_{m=1}^{M} \Phi\left( \frac{\mu_{c,m}(\mathbf{x})}{\sigma_{c,m}(\mathbf{x})} \right)$

where $\gamma(\mathbf{x}) = \frac{f_{\min}^+ - \mu_t(\mathbf{x})}{\sigma_t(\mathbf{x})}$, and $\Phi(\cdot)$ and $\phi(\cdot)$ denote the cumulative distribution function and probability density function of the standard normal distribution, respectively.

In 2026, two major algorithmic extensions have further accelerated Bayesian transistor sizing across industrial design flows . First, Knowledge Alignment and Transfer (`KATO`) addresses the challenge of migrating an analog IP block from a legacy FinFET node to a 3nm GAA nanosheet technology by aligning the latent GP response surfaces across technology nodes, warm-starting the 3nm sizing optimization using historical SPICE data . Second, diffusion-based sizing priors overcome the cubic $O(t^3)$ Cholesky decomposition scaling and boundary-seeking behavior that afflict standard Gaussian Processes in high-dimensional circuits ($d > 50$) . By integrating pre-trained generative diffusion priors over valid electrical operating spaces—such as the $g_m/I_D$ or $R_{on}/g_m$ inversion-coefficient manifold used in dynamic amplifier methodologies—the acquisition search is restricted strictly to physically viable biasing regions .

## 19.8 REINFORCEMENT LEARNING FOR ANALOG TOPOLOGY GENERATION

While Bayesian Optimization excels at tuning continuous device parameters within a fixed schematic, it cannot invent a new circuit schematic or alter the wiring graph . Historically, analog circuit topology selection relied entirely on human intuition and textbook templates. By 2026, Deep Reinforcement Learning (DRL), Graph Neural Networks (GNNs), and grammar-guided generative decoding frameworks have automated both transferable transistor sizing (`AutoCkt`, `GCN-RL`, `AnalogGym`) and full device-level analog topology synthesis (`AnalogToBi`, `CABAgent`) .

### MARKOV DECISION PROCESS FORMULATION AND ELECTRICAL DESIGN SPACES

In a simulator-guided RL loop, the headless SPICE binary functions as the deterministic or stochastic environment within an OpenAI `Gymnasium`-compatible interface such as `AnalogGym` . The synthesis task is formulated as a Markov Decision Process (MDP) defined by the tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$, where the state space $\mathcal{S}$ represents the circuit as an attributed bipartite graph $\mathcal{G} = (\mathcal{V}_D, \mathcal{V}_N, \mathcal{E})$ within graph-based policy architectures like `GCN-RL` . In this bipartite representation, $\mathcal{V}_D$ represents device terminals (MOSFETs, capacitors, resistors, power rails), $\mathcal{V}_N$ represents electrical nets, and edges $\mathcal{E}$ define topological connectivity . Rather than feeding raw geometric dimensions $(W, L)$ as state features—which fail to transfer across foundry PDKs—modern RL agents operate within an Electrical Design Space . At step $t$, the state vector $\mathbf{s}_t \in \mathcal{S}$ encodes the current graph adjacency matrix alongside DC operating point electrical features extracted from SPICE, including transconductance efficiency $(g_m/I_D)$, overdrive voltage $(V_{GS} - V_{TH})$, drain-source saturation margin $(V_{DS} - V_{DS,\text{sat}})$, and node impedances .

The corresponding action space $\mathcal{A}$ is structured hierarchically to accommodate both structural wiring decisions and continuous parameter tuning . High-level discrete actions select production rules from a Bipartite Graph Grammar (`AnalogToBi`) or invoke Monte Carlo Tree Search (MCTS) branches to insert, delete, or connect fundamental building blocks such as current mirrors, cascode stages, differential pairs, and Miller compensation networks . Concurrently, low-level continuous actions output normalized parameter adjustments $\mathbf{a}_t \in [-1, 1]^d$ executed via Twin Delayed Deep Deterministic Policy Gradient (`TD3`) or Proximal Policy Optimization (`PPO`) agents . When the RL agent emits a candidate netlist, the headless SPICE environment executes `.op`, `.ac`, and `.tran` simulations to evaluate the reward function $\mathcal{R}$ by extracting performance metrics $m_k(\mathbf{s}_t)$ against target design specifications $m_k^*$ . To overcome sparse reward stagnation when early topologies fail to oscillate or amplify, a piecewise smooth Figure-of-Merit (FoM) reward shapes the gradient landscape :

$R(\mathbf{s}_t, \mathbf{a}_t) = \begin{cases} -P_{\text{invalid}} & \text{if SPICE fails to converge or violates ERC} \\ \sum_{k=1}^{K} w_k \min\left( 0, \frac{m_k(\mathbf{s}_t) - m_k^*}{m_k(\mathbf{s}_t) + m_k^*} \right) & \text{if any specification } m_k(\mathbf{s}_t) < m_k^* \\ R_{\text{base}} + \sum_{j \in \mathcal{J}_{\text{opt}}} \beta_j \frac{m_j^* - m_j(\mathbf{s}_t)}{m_j^*} & \text{if all hard constraints are satisfied} \end{cases}$

### BIPARTITE GRAPH DECODING AND SELF-EVOLVING LLM AGENTS

A major breakthrough in 2026 topology synthesis is the elimination of invalid random graphs (such as shorted voltage rails or floating MOSFET gates) prior to invoking SPICE . Frameworks like `AnalogToBi` utilize Bipartite Graph and Grammar-Guided Decoding to guarantee that every generated token sequence maps to a syntactically and electrically valid SPICE netlist . Concurrently, layout-aware agentic frameworks such as `CABAgent` pair self-evolving Large Language Model (LLM) agents with GNN-RL policies and automated digital-style Place-and-Route (`Acell`-based layout) . By evaluating layout parasitics in the RL loop, `Acell`-based automated AMS layouts achieve circuit performance matching manual `Pcell` designs with only a $2\%$ area overhead, while empirical Bayes placement methodologies reduce Design Rule Check (DRC) violations by up to $10\times$, wirelength by $5\%$, and Worst/Total Negative Slack (WNS/TNS) by $30\%$ and $60\%$, respectively .

### PRODUCTION PYTHON CODE: GYMNASIUM RL ENVIRONMENT WRAPPING HEADLESS SPICE

The following production-ready Python code implements a `Gymnasium`-compliant Reinforcement Learning environment that couples a PyTorch policy network directly to the in-memory `HeadlessSpiceEngine`.

```python
import gymnasium as gym
from gymnasium import spaces
import numpy as np
import torch

class SpiceAnalogSizingEnv(gym.Env):
    """
    OpenAI Gymnasium-compatible Reinforcement Learning environment wrapping 
    an in-memory headless SPICE solver for autonomous circuit optimization.
    """
    def __init__(self, spice_engine: HeadlessSpiceEngine, target_bw_hz: float = 2e9, max_steps: int = 40):
        super().__init__()
        self.spice = spice_engine
        self.target_bw = target_bw_hz
        self.max_steps = max_steps
        self.current_step = 0
        
        # Parameter bounds: [W_n (m), W_p (m), R_load (Ohm)]
        self.param_min = np.array([20e-9, 40e-9, 500.0], dtype=np.float32)
        self.param_max = np.array([2000e-9, 4000e-9, 10000.0], dtype=np.float32)
        self.current_params = np.mean([self.param_min, self.param_max], axis=0)
        
        # Continuous Action Space: relative adjustments in [-1.0, +1.0]
        self.action_space = spaces.Box(low=-1.0, high=1.0, shape=(3,), dtype=np.float32)
        
        # Observation Space: Normalized params + [DC_Gain, Slew_Rate, Power_mW, Settling_Error]
        self.observation_space = spaces.Box(low=-np.inf, high=np.inf, shape=(7,), dtype=np.float32)

    def _normalize_params(self, p: np.ndarray) -> np.ndarray:
        return 2.0 * (p - self.param_min) / (self.param_max - self.param_min) - 1.0

    def _simulate_and_extract(self) -> Tuple[np.ndarray, float, bool]:
        # Mutate C-heap parameters directly without file IO
        self.spice.mutate_parameter("m1", "w", float(self.current_params[0]))
        self.spice.mutate_parameter("m2", "w", float(self.current_params[1]))
        self.spice.mutate_parameter("rload", "resistance", float(self.current_params[2]))
        
        tensors = self.spice.run_transient(t_step="1p", t_stop="500p")
        if "v(out)" not in tensors or len(tensors["v(out)"]) < 10:
            # Solver convergence failure penalty
            return np.zeros(4, dtype=np.float32), -10.0, True
            
        v_out = tensors["v(out)"].cpu().numpy()
        t_vec = tensors["time"].cpu().numpy()
        
        # Extract electrical state features
        v_swing = float(np.max(v_out) - np.min(v_out))
        dt = np.diff(t_vec) + 1e-18
        slew_rate = float(np.max(np.abs(np.diff(v_out) / dt))) * 1e-9  # V/ns
        est_power_mw = float((1.0 ** 2) / self.current_params[2]) * 1e3
        settling_err = float(np.abs(v_out[-1] - 0.5))
        
        elec_feats = np.array([v_swing, slew_rate, est_power_mw, settling_err], dtype=np.float32)
        
        # Compute shaped Figure-of-Merit (FoM) reward
        r_swing = min(0.0, (v_swing - 0.6) / (v_swing + 0.6))
        r_slew = min(0.0, (slew_rate - 5.0) / (slew_rate + 5.0))
        if r_swing == 0.0 and r_slew == 0.0:
            reward = 5.0 - 0.5 * est_power_mw - 2.0 * settling_err
            terminated = True
        else:
            reward = float(r_swing + r_slew - 0.05 * est_power_mw)
            terminated = False
            
        return elec_feats, reward, terminated

    def reset(self, seed: Optional[int] = None, options: Optional[dict] = None):
        super().reset(seed=seed)
        self.current_step = 0
        self.current_params = self.np_random.uniform(self.param_min, self.param_max).astype(np.float32)
        elec_feats, _, _ = self._simulate_and_extract()
        obs = np.concatenate([self._normalize_params(self.current_params), elec_feats])
        return obs, {}

    def step(self, action: np.ndarray):
        self.current_step += 1
        step_delta = 0.1 * (self.param_max - self.param_min) * np.clip(action, -1.0, 1.0)
        self.current_params = np.clip(self.current_params + step_delta, self.param_min, self.param_max)
        
        elec_feats, reward, terminated = self._simulate_and_extract()
        truncated = self.current_step >= self.max_steps
        obs = np.concatenate([self._normalize_params(self.current_params), elec_feats])
        return obs, reward, terminated, truncated, {}
```

## 19.9 DIGITAL TWINS: SYNCING SPICE WITH PHYSICAL IOT DATA

The utility of a headless SPICE engine or neural circuit surrogate does not terminate when a chip is taped out and fabricated. In mission-critical 2026 deployments—such as electric vehicle silicon-carbide (SiC) and gallium-nitride (GaN) power inverters, aerospace rad-hardened telemetry systems, implantable machine-learning-aided healthcare sensing devices, and non-volatile in-memory computing arrays—physical silicon degrades continuously over its operational lifetime . Mechanisms including Hot Carrier Injection (HCI), Bias Temperature Instability (BTI), electromigration, and conductive filament (CF) resistive drift in $\text{HfO}_2$/$\text{V}_2\text{O}_3$ RRAM arrays progressively shift threshold voltages $V_{TH}$, degrade low-field mobility $\mu_0$, and increase amplifier offset voltages .

### CLOSED-LOOP TELEMETRY AND BAYESIAN PARAMETER CALIBRATION

A SPICE Digital Twin is a continuously executing virtual replica of a physical integrated circuit that synchronizes its internal compact model parameters $\boldsymbol{\theta}_k$ in real time using streaming telemetry from on-die IoT hardware sensors . Modern mixed-signal ICs embed lightweight on-chip monitors: ring-oscillator aging sensors, stacked-device MOSFET matching matrix arrays requiring only basic DC readings, dynamic $V_{DD}$ IR-drop monitors, and thermal diodes . These physical measurements $\mathbf{y}_k \in \mathbb{R}^m$ are transmitted via MQTT or gRPC over industrial IoT gateways to a cloud or edge-hosted headless SPICE twin.

To reconcile discrepancies between the physical silicon telemetry $\mathbf{y}_k$ and the simulated SPICE output $\mathbf{h}(\boldsymbol{\theta}_k, \mathbf{u}_k)$, the Digital Twin formulates parameter synchronization as a nonlinear state-estimation problem solved via an Unscented Kalman Filter (UKF) or Differentiable Surrogate Adjoint Filtering . Let the slowly varying degradation parameter vector be $\boldsymbol{\theta}_k = [\Delta V_{TH}, \mu_{r0}, DUA, R_{\text{parasitic}}, T_{\text{latent}}]^T$, which evolves according to a stochastic drift process :

$\boldsymbol{\theta}_{k} = \boldsymbol{\theta}_{k-1} + \mathbf{w}_{k-1}, \quad \mathbf{w}_{k-1} \sim \mathcal{N}(\mathbf{0}, \mathbf{Q}_k)$

$\mathbf{y}_k = \mathbf{h}_{\text{SPICE}}(\boldsymbol{\theta}_k, \mathbf{u}_k) + \mathbf{v}_k, \quad \mathbf{v}_k \sim \mathcal{N}(\mathbf{0}, \mathbf{R}_k)$

where $\mathbf{Q}_k$ and $\mathbf{R}_k$ represent the process drift covariance and sensor measurement noise covariance matrices, respectively. When $\mathbf{h}_{\text{SPICE}}$ is backed by a differentiable neural compact model or quasi-physical GAA function, the observation Jacobian $\mathbf{H}_k = \left. \frac{\partial \mathbf{h}}{\partial \boldsymbol{\theta}} \right|_{\hat{\boldsymbol{\theta}}_{k|k-1}}$ is computed instantaneously via backpropagation . The Kalman gain $\mathbf{K}_k$ and posterior parameter state update $\hat{\boldsymbol{\theta}}_{k|k}$ follow directly:

$\mathbf{K}_k = \mathbf{P}_{k|k-1} \mathbf{H}_k^T \left( \mathbf{H}_k \mathbf{P}_{k|k-1} \mathbf{H}_k^T + \mathbf{R}_k \right)^{-1}$

$\hat{\boldsymbol{\theta}}_{k|k} = \hat{\boldsymbol{\theta}}_{k|k-1} + \mathbf{K}_k \left( \mathbf{y}_k - \mathbf{h}_{\text{SPICE}}(\hat{\boldsymbol{\theta}}_{k|k-1}, \mathbf{u}_k) \right)$

### LATENT ELECTROTHERMAL RECOVERY AND SELF-HEALING CALIBRATION

Once the Digital Twin updates $\hat{\boldsymbol{\theta}}_{k|k}$ via the `altermod` C-API in the headless SPICE instance, the synchronized simulator unlocks two critical diagnostic and control capabilities that physical sensors alone cannot provide . First, the Digital Twin enables unobservable internal node and latent thermal inference; because physical packaging prevents placing thermal probes directly inside individual 3D-stacked neuromorphic layers or buried backside power rails, assimilating ordered electrical terminal trajectories into structure-regularized recurrent compact models (such as $\Psi$-Vortex) or electrothermal memristor companions (`HP-ATFM`) allows the simulator to recover latent internal thermal coupling and predict impending hot-carrier breakdown before physical failure occurs . Second, the Digital Twin executes closed-loop self-healing actuation; when the synchronized SPICE instance detects that aging has degraded phase margin or increased amplifier offset voltage, it runs a rapid local optimization loop to compute compensatory DAC trim codes—such as body-bias adjustments or repeatable offset compensation states that maintain amplifier offset below $57.8\text{ }\mu\text{V}$ while occupying only $1829\text{ }\mu\text{m}^2$ of silicon area—and transmits the corrective configuration back to the physical IoT hardware .

## 19.10 THE HYBRID ENGINE: ML INFERENCE INSIDE THE SPICE LOOP

While pure circuit-level AI surrogates (Chapter 5) excel at rapid block-level exploration, full-chip signoff verification still demands the mathematical guarantees of the global Modified Nodal Analysis (MNA) conservation laws (Kirchhoff's Current and Voltage Laws across millions of interconnected parasitic nodes). Consequently, the crowning architectural achievement of 2026 EDA is the Hybrid SPICE Engine: embedding pre-trained, physics-constrained neural network device models directly inside the compiled C-code MNA matrix evaluation loop via the OpenVAF compiler and the Open Simulator Device Interface (OSDI) .

### THE OPENVAF AND OSDI IN-LOOP ARCHITECTURE

Historically, integrating a novel device model into a commercial or open-source SPICE engine required hand-coding tens of thousands of lines of C code to compute currents, charges, and analytical partial derivatives, or relying on slow interpreted Verilog-A modules . In the modern open EDA ecosystem, `OpenVAF` serves as an LLVM-backed Verilog-A compiler middleware that compiles behavioral and neural-network compact models into machine-code, OSDI-compliant shared objects (`.osdi`) that load natively into `ngspice` (version 44+) and commercial simulators .

Within this hybrid architecture, the neural compact model consists of decoupled or joint Current-Voltage ($IV$) and Charge-Voltage ($QV$) sub-networks . At every Newton-Raphson iteration $k$ of timestep $t_n$, the C-code SPICE engine queries every nonlinear transistor instance with the trial terminal voltage vector $\mathbf{v}^{(k)} = [V_{GS}^{(k)}, V_{DS}^{(k)}, V_{BS}^{(k)}]^T$. Instead of evaluating hundreds of transcendental `exp()`, `log()`, and `pow()` calls inside BSIM-CMG, the OSDI shared object executes a vectorized forward pass through a lightweight, quantized or centroid-clustered multilayer perceptron (MLP) to compute terminal currents $\mathbf{I}(\mathbf{v}^{(k)})$ and charges $\mathbf{Q}(\mathbf{v}^{(k)})$, alongside a simultaneous analytical Jacobian pass to stamp the exact conductances $g_{ij} = \frac{\partial I_i}{\partial V_j}$ and capacitances $C_{ij} = \frac{\partial Q_i}{\partial V_j}$ directly into the sparse MNA matrix .

### ANALYTICAL IN-LOOP JACOBIAN STAMPING VIA FORWARD DERIVATIVE PROPAGATION

A critical mathematical requirement of the Newton-Raphson solver is that the stamped conductances $g_m$ and $g_{ds}$ must be the exact analytical derivatives of the evaluated current $I_D$ with respect to the terminal voltages; using finite-difference approximations ($\frac{I(V+\Delta V) - I(V)}{\Delta V}$) introduces numerical noise that destroys quadratic Newton-Raphson convergence near zero crossings .

For an $L$-layer neural compact model where layer $\ell \in \{1, \dots, L\}$ computes pre-activation $\mathbf{z}^{(\ell)} = \mathbf{W}^{(\ell)} \mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}$ and activation $\mathbf{a}^{(\ell)} = \sigma_{\ell}(\mathbf{z}^{(\ell)})$ with $\mathbf{a}^{(0)} = \mathbf{v}$ and $\sigma_{\ell}(z) = \tanh(z)$, the OSDI C-routine computes both the forward inference and the exact Jacobian matrix $\mathbf{J}_{\text{NN}}(\mathbf{v}) = \frac{\partial \mathbf{a}^{(L)}}{\partial \mathbf{v}}$ in a single fused memory pass without requiring an external deep learning framework at runtime :

$\mathbf{a}^{(\ell)} = \tanh\left(\mathbf{W}^{(\ell)} \mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}\right), \quad \text{diag}\left(\sigma'_{\ell}(\mathbf{z}^{(\ell)})\right) = \text{diag}\left(\mathbf{1} - \left(\mathbf{a}^{(\ell)}\right)^{\odot 2}\right)$

$\frac{\partial \mathbf{a}^{(\ell)}}{\partial \mathbf{v}} = \text{diag}\left(\mathbf{1} - \left(\mathbf{a}^{(\ell)}\right)^{\odot 2}\right) \mathbf{W}^{(\ell)} \frac{\partial \mathbf{a}^{(\ell-1)}}{\partial \mathbf{v}}, \quad \text{initialized with } \frac{\partial \mathbf{a}^{(0)}}{\partial \mathbf{v}} = \mathbf{I}$

The computational elegance of this formulation lies in the algebraic property of the hyperbolic tangent: because the derivative of $\tanh(z)$ is simply $1 - \tanh^2(z) = 1 - (a^{(\ell)})^2$, the derivative of every neuron activation is already known from its forward-pass output via a single subtraction and multiplication, completely avoiding redundant transcendental function evaluations .

### COMPUTATIONAL COMPLEXITY AND MEMORY FOOTPRINT OF IN-LOOP NEURAL MODELS

To fit inside the Level-1 (L1) CPU data cache of the SPICE thread executing the MNA matrix assembly, the neural compact model must be strictly bounded in operation count and byte-level memory footprint . A fully connected layer mapping $n_{\ell-1} \rightarrow n_\ell$ neurons requires a standard operation count of $\text{OPS}_\ell^{\text{standard}} = n_\ell(2n_{\ell-1} + 1)$ . When weight pruning and centroid clustering are applied, treating parameter sharing as a memory benefit rather than an arithmetic reduction yields an effective per-layer operation count of :

$\text{OPS}_\ell^{\text{effective}} = \left|\left\{(i, j) : R_{ij}^{(\ell)} \neq 0\right\}\right| + n_\ell + C_\ell, \quad \text{OPS}_{\text{total}} = \sum_{\ell=1}^{L} \text{OPS}_\ell^{\text{effective}}$

where $C_\ell = 3n_\ell$ accounts for the $\tanh$ activation operations . Furthermore, when weights are compressed via centroid clustering into $K_\ell \le 127$ distinct floating-point centroids per layer, each parameter maps to a single 1-byte signed index ($S_{\text{idx}} = 1\text{ B}$) alongside 4-byte FP32 centroids ($S_{\text{param}} = 4\text{ B}$), yielding an exact deployable weight and activation memory footprint of :

$M_{\text{weights}} = \sum_{\ell=1}^{L} K_\ell S_{\text{param}} + \sum_{\ell=1}^{L} \left(n_{\ell-1} n_\ell + n_\ell\right) S_{\text{idx}}, \quad M_{\text{activations}} = \sum_{\ell=1}^{L} n_\ell S_{\text{param}}$


As established by the architectural analysis of the `[2, 40, 40, 40, 2]` memristor compact model, evaluating the entire neural network requires only $3,360$ weight operations, $122$ bias additions, and $360$ $\tanh$ activation operations ($3 \times 120$ across the three hidden layers), totaling $3,842$ operations . When compressed to $K=21$ FP32 centroids across $3,482$ total parameters, the centroids themselves occupy merely $84\text{ Bytes}$, while the 1-byte signed relation indices occupy $3,482\text{ Bytes}$, resulting in a total weight storage footprint of just $3,566\text{ Bytes}$ ($3.57\text{ KB}$) . Because the entire model fits effortlessly inside the 32 KB or 64 KB L1 data cache of a modern processor core, cache misses during MNA matrix stamping are completely eliminated, enabling SPICE-compatible neural compact models to achieve $40\times$ speedups over conventional analytical compact models .

### C-LEVEL AND VERILOG-A/OSDI HYBRID MATRIX EVALUATION CODE

To conclude Volume 19, the following production implementation demonstrates the two-stage hybrid integration workflow used in 2026: first, a Python script that exports a trained PyTorch neural compact model into a vectorized Verilog-A/OSDI C-routine; and second, the exact in-loop C matrix evaluation kernel that stamps $I_{DS}$, $g_m$, and $g_{ds}$ into the SPICE MNA solver.

```python
import torch
import numpy as np

def export_pytorch_model_to_osdi_c_header(model: torch.nn.Sequential, header_path: str = "nn_compact_weights.h") -> None:
    """
    Extracts trained PyTorch Linear layer weights and biases and serializes them 
    into cache-aligned C arrays for direct inclusion in an OSDI / C SPICE device evaluation loop.
    """
    linear_layers = [m for m in model.modules() if isinstance(m, torch.nn.Linear)]
    lines = [
        "/* AUTO-GENERATED 2026 HYBRID SPICE NEURAL COMPACT MODEL WEIGHTS */",
        "#ifndef NN_COMPACT_WEIGHTS_H",
        "#define NN_COMPACT_WEIGHTS_H",
        ""
    ]
    for idx, layer in enumerate(linear_layers):
        w = layer.weight.detach().cpu().numpy().astype(np.float64)
        b = layer.bias.detach().cpu().numpy().astype(np.float64)
        out_dim, in_dim = w.shape
        
        w_flat = ", ".join([f"{val:.12e}" for val in w.flatten()])
        b_flat = ", ".join([f"{val:.12e}" for val in b.flatten()])
        
        lines.append(f"#define LAYER_{idx}_IN {in_dim}")
        lines.append(f"#define LAYER_{idx}_OUT {out_dim}")
        lines.append(f"static const double W_{idx}[{out_dim * in_dim}] __attribute__((aligned(64))) = {{ {w_flat} }};")
        lines.append(f"static const double B_{idx}[{out_dim}] __attribute__((aligned(64))) = {{ {b_flat} }};")
        lines.append("")
        
    lines.append("#endif /* NN_COMPACT_WEIGHTS_H */")
    with open(header_path, "w", encoding="utf-8") as f:
        f.write("\n".join(lines))

# Below is the C-kernel executed inside the OSDI / SPICE Newton-Raphson evaluation loop
OSDI_C_KERNEL_SOURCE = r"""
#include <math.h>
#include "nn_compact_weights.h"

/*
 * Evaluates a [2 -> 40 -> 1] Quasi-Physical Neural Compact Model and its exact
 * analytical Jacobian derivatives (gm = dIds/dVgs, gds = dIds/dVds) inside the
 * SPICE MNA Newton-Raphson loop.
 */
void evaluate_neural_fet_osdi(
    double vgs, double vds,
    double *ids_out, double *gm_out, double *gds_out
) {
    double a1[40];
    double da1_dvgs[40];
    double da1_dvds[40];

    /* Forward & Analytical Tangent Propagation through Hidden Layer 0 (2 -> 40) */
    for (int i = 0; i < 40; ++i) {
        double w_vgs = W_0[i * 2 + 0];
        double w_vds = W_0[i * 2 + 1];
        double z = w_vgs * vgs + w_vds * vds + B_0[i];
        double t = tanh(z);
        double dt_dz = 1.0 - (t * t); /* Exact analytical derivative of tanh(z) */

        a1[i] = t;
        da1_dvgs[i] = dt_dz * w_vgs;
        da1_dvds[i] = dt_dz * w_vds;
    }

    /* Output Layer Accumulation (40 -> 1) with Thermodynamic Zero-Bias Enforcement */
    double nn_val = B_1[0];
    double dnn_dvgs = 0.0;
    double dnn_dvds = 0.0;

    for (int i = 0; i < 40; ++i) {
        double w_out = W_1[i];
        nn_val += w_out * a1[i];
        dnn_dvgs += w_out * da1_dvgs[i];
        dnn_dvds += w_out * da1_dvds[i];
    }

    /* Multiply by Vds to guarantee exact zero current (Ids = 0) at Vds = 0 */
    *ids_out = vds * nn_val;
    *gm_out  = vds * dnn_dvgs;
    *gds_out = nn_val + vds * dnn_dvds;
}
"""
```

By multiplying the neural network output by $V_{DS}$ in the final C-stamping stage (`*ids_out = vds * nn_val`) and applying the product rule to the output conductance (`*gds_out = nn_val + vds * dnn_dvds`), this hybrid evaluation kernel strictly enforces thermodynamic passivity ($I_{DS} = 0$ at $V_{DS} = 0$) while providing exact analytical derivatives to the sparse matrix solver .
